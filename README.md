
# Student Performance Prediction using Machine Learning

## Overview
A machine learning project that estimates student final marks using study hours, attendance percentage, and previous marks.

## Technologies
- Python
- Pandas
- Scikit-learn
- Streamlit

## Features
- CSV dataset loading
- Linear Regression model
- MAE and R² evaluation
- Interactive Streamlit interface

## Installation
```bash
python -m pip install -r requirements.txt
```

## Run the application
```bash
python -m streamlit run app.py
```

## Dataset
The included dataset is synthetic and intended for educational demonstration only. Predictions are not guaranteed to be accurate for real students.
