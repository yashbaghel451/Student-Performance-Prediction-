STUDENT PERFORMANCE PREDICTION USING MACHINE LEARNING
Mini Project Report

1. ABSTRACT
This project demonstrates a basic machine-learning system that estimates final student marks from weekly study hours, attendance percentage, and previous marks. Linear Regression is used to learn a relationship between the input variables and final marks.

2. PROBLEM STATEMENT
Students and educators may want to understand how learning-related indicators can be analysed. This project presents a small educational prototype that estimates marks from a few simplified inputs.

3. OBJECTIVES
- Understand a supervised machine-learning workflow.
- Prepare and read data using pandas.
- Train a Linear Regression model using scikit-learn.
- Evaluate predictions using MAE and R-squared.
- Accept new input values and produce an estimated score.

4. TOOLS AND TECHNOLOGIES
Python, pandas, scikit-learn, CSV dataset, command-line interface.

5. DATASET
The included CSV contains 30 synthetic demonstration records. Input features are study_hours_per_week, attendance_percent, and previous_marks. The target is final_marks. These records are fictional and must not be described as real student data.

6. METHODOLOGY
The dataset is loaded using pandas. The three input columns are separated from the target column. The records are divided into training and testing subsets using train_test_split. Linear Regression is trained on the training subset. The model is evaluated on the test subset using Mean Absolute Error (MAE) and R-squared. Finally, the program accepts user input and estimates marks.

7. ALGORITHM
Linear Regression estimates a linear relationship between input features and the target value. It learns coefficients from the training data and uses them to estimate the target for new inputs.

8. HOW TO RUN
Install dependencies with: python -m pip install -r requirements.txt
Run the project with: python main.py

9. EXPECTED OUTPUT
The program displays MAE and R-squared, asks for study hours, attendance and previous marks, and prints an estimated final mark out of 100. Exact values depend on the included demo dataset.

10. LIMITATIONS
The dataset is small and synthetic. The model is for learning purposes only and is not suitable for actual grading or decisions about students. Real outcomes depend on many factors not included here.

11. CONCLUSION
This mini-project demonstrates the main stages of supervised learning: data loading, feature selection, train/test split, model training, evaluation, and prediction. Future improvements could include a larger real and ethically collected dataset, a simple graphical interface, and comparison with other regression models.
